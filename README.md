# VELARIS | Ultra-Premium Scent Universe

![VELARIS Luxury Banner]

> "Where scent becomes a digital masterpiece."

**VELARIS** is an avant-garde, ultra-premium digital experience designed for the modern connoisseur of fine fragrances. This is not just a store; it is an immersive editorial journey through the psychology of scent.

## ✨ The Experience

- **Immersive Editorial Gallery**: A high-fashion, museum-style product showcase with smooth parallax effects and cinematic transitions.
- **Scent Discovery Quiz**: An interactive, AI-driven concierge that identifies your unique olfactory archetype through sensory questions.
- **Dynamic Manifestos**: Each perfume category features its own atmospheric environment, with custom glows, background typography, and poetic quotes.
- **Cinematic Interactivity**: Powered by GSAP and Lenis for buttery-smooth scrolling and fluid animations that react to your presence.
- **Mobile Perfection**: A completely responsive architecture tailored for iPad Pro and high-end mobile devices, featuring a minimalist velvet-menu system.

## 🛠 Tech Stack

- **Core**: HTML5, Vanilla CSS3
- **Animations**: [GSAP](https://gsap.com/) (GreenSock Animation Platform)
- **Smooth Scrolling**: [Lenis](https://github.com/darkroomengineering/lenis)
- **Engine**: Node.js (Express server)
- **Design Philosophy**: Editorial, Minimalist, Luxury

## 🚀 Installation & Launch

To experience the world of VELARIS locally:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/abdelhameeed10/perfume-store.git
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Launch the server**:
   ```bash
   node server.js
   ```

4. **Visit the universe**:
   Open `http://localhost:4000` in your browser.

## 🔒 Security & Safety

- **No Secrets**: This is a frontend-focused architectural demonstration. No sensitive API keys or database credentials are stored in the repository.
- **Dependency Management**: Standard `package.json` is used for safe, version-controlled library management.
- **Optimized Assets**: High-resolution assets are optimized for fast loading and secure distribution.
